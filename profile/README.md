# Ai-road-4-You — iAiFy Enterprise

Shared platform, CI/CD och governance for hela iAiFy: enterprise-wide workflows, composite actions, policies och repo-templates som konsumeras av alla orgs.

## Flaggskeppsrepos

- [enterprise-ci-cd](https://github.com/Ai-road-4-You/enterprise-ci-cd) — 38 reusable workflows — CI/CD-hubben for ALLA repos (YAML, Shell)
- [governance](https://github.com/Ai-road-4-You/governance) — Central governance: policies, runbooks och enterprise-analysis
- [github-actions](https://github.com/Ai-road-4-You/github-actions) — 17 composite actions (v1.1.0) — deploy, test, lint, security-scan
- [repo-templates](https://github.com/Ai-road-4-You/repo-templates) — Bootstrap templates for nya repos over alla orgs

## Shared conventions

- Kebab-case repo names
- Conventional commits
- Infrastructure-as-code via terraform-infrastructure
- CI/CD via Ai-road-4-You/enterprise-ci-cd@v1
